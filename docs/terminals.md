# Terminals and editors

## Mitos

Every host selects `ms` (Mitos) as `EDITOR`, with Neovim kept alongside it.
`e` and Nushell's buffer editor follow `EDITOR`. Helix and Zed remain optional
modules. Settings in `config/mitos/` are live links; themes come from the pinned
Solforge input. Xcode supplies Swift's language server on Macs.

`packages/mitos.nix` packages the upstream release binary and its prebuilt
parsers, avoiding a Rust and grammar rebuild on a switch. To update it, change
`version` and the three platform hashes from the release's `SHA256SUMS`, run
`nix build .#mitos` on the target platform, then check
`./result/bin/ms --health rust`.

Mitos installs its own language tools, independently of Neovim: Marksman for
Markdown, Taplo for TOML, the JSON and YAML servers, Pyright and Ruff for
Python, `typescript-language-server` and TypeScript for JS/TS, and nixd with
nixfmt for Nix. Swift uses Xcode's `sourcekit-lsp` on Macs.

`:format` uses dprint for Markdown, JSON/JSONC, TOML and YAML. Project dprint
configuration takes precedence. Loose files fall back to
`config/dprint/dprint.jsonc`. The global config has no JS/TS plugin, so those
languages keep the TypeScript server's formatter. Format-on-save and autosave
are off. Indentation guides, soft wrapping and hidden files in the picker are
on. Inlay hints remain off.

After changing language settings, use `:lsp-restart`. Check tool availability
with `ms --health <language>`; that checks executables without starting servers.
Use `:config-reload` after changing the main editor settings.

## Rex on Macs

Rex is the selected Mac terminal. Install its signed app from
<https://www.superlogical.com/rex>; it has no Homebrew cask and updates itself.
Nix owns `~/.config/rex/init.lua`, the Solforge theme selections and their data.
It preserves custom themes with other IDs. Relaunch Rex after a theme change.

After the first switch:

1. In **Rex → Settings → Terminal → Shell**, set the startup command to
   `/etc/profiles/per-user/<account>/bin/nu-login`, replacing `<account>` with
   the macOS account name. `command -v nu-login` gives its path in a new shell.
   The launcher loads the Nix environment through zsh, then starts nu. zsh
   remains the account's login shell. The Rex module restores the CLI directory
   from `REX_BIN_DIR` after Nix resets PATH, including for direct nu launches.
2. Run `rex skill setup --autostart=false` to install its current agent skill
   and hooks. Repeat after adding an agent.
3. Run `pi-setup` for the extensions and memory wiki.

The Rex theme JSON in `config/rex/solforge.json` was generated by
`solforge-theme` commit `c9f87f3f4ea1b75836c61273a6e6abb704d30fc4`, which was
local-only during this migration. Once that commit is published and the input
bumped, replace the vendored file with `${inputs.solforge-theme}/rex/solforge.json`
in `modules/darwin/apps/rex.nix`.

## Nushell

Terminals open nu through `nu-login`; zsh stays the login shell and `$SHELL`.
`config/nushell/config.nu` holds options, keys, aliases and small commands, and
loads the modules in `config/nushell/scripts/`: the prompt, Tern's integration,
fish-style editing, completions, worktrees and ssh. Both are live links. Only
exported commands reach the shell; helpers stay private to their module.
`modules/common/shell/nushell.nix` generates the Atuin, fnox, zoxide, carapace
and direnv init into the vendor autoload directory, and fails the build
when nu cannot parse it.

Alt-C, or `p` with words to match, enters a project: a directory in `~/src`
or a worktree root, or a mark. `$env.PROJECTS` in `config.nu` lists both;
zoxide's score ranks them. Ctrl-F in the picker enters the pick and runs `ft`
there.

`glog` and `gst` return git's log and status as tables to filter and pipe;
`gb` switches branches. `ft <ext>` finds files by type and acts on the picks,
`mdp` previews and reads markdown, and `mdh` lists a file's headings.
`help <command>` shows each one's keys and examples. delta renders diffs for
git and lazygit.

The prompt, `ga`/`gd` and the ssh wrapper exist in both shells; change them
together. `nix build .#checks.<system>.shell` loads the config in a scratch home
and runs the worktree helpers in both shells.

## Optional browser and other terminals

Terminal-browser's stable v0.15.3 predates its Rex backend. For now, install
its dev channel explicitly using <https://terminal-browser.sh/install/dev>;
review the installer before running it. It manages its own files and skill.
Nix disables its telemetry when the Rex module is enabled. No network installer
runs during system activation. Revisit packaging it when a stable release
includes Rex support.

Ghostty remains enabled on amarna, where Rex has no native desktop client.
Its canonical config is `config/ghostty/config`; the generated `shell.ghostty`
include launches Nushell. The existing Tern and Herdr modules remain optional.
The macOS hosts no longer enable Tern, Ghostty, Helix or Zed by default.
